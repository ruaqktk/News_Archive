# 언론사 로고

이 폴더에 언론사 공식 로고 파일을 넣으면 사이트의 언론사 카드 이름 옆에 표시됩니다.
파일이 없는 언론사는 이름만 표시됩니다.

- 파일 이름: `<언론사ID>.svg` 또는 `<언론사ID>.png` (SVG를 먼저 찾습니다). 현재는 글자 높이를 맞춘 2배 해상도 PNG(높이 56px)를 씁니다.
- 권장 크기: 높이 56px 이상의 가로형 로고, 투명 배경 (화면에는 높이 28px로 줄여 표시)
