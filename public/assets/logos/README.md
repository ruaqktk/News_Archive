# 언론사 로고

파일이 없는 언론사는 이름만 표시됩니다.

- 파일 이름: `<언론사ID>.svg` 또는 `<언론사ID>.png` (SVG를 먼저 찾습니다).
- 권장 형식: 원형으로 다듬은 정사각 PNG(56×56 이상), 원 바깥 투명 (화면에는 40px로 표시)
